## 文件格式

每個數據集包含以下CSV文件：
- `proverbs_full_20250823_131449.csv` - 完整數據集
- `proverbs_train_20250823_131449.csv` - 訓練集
- `proverbs_val_20250823_131449.csv` - 驗證集
- `proverbs_test_20250823_131449.csv` - 測試集

### CSV列說明
- `text`: 文本內容
- `length`: 詞數
- `char_count`: 字符數
- `dataset_name`: 數據集名稱
- `dataset_description`: 數據集描述
- `source`: 數據來源

## 使用方法

### Python (pandas)
```python
import pandas as pd

# 讀取訓練集
train_df = pd.read_csv('proverbs_train_20250823_131449.csv')

# 讀取文本
texts = train_df['text'].tolist()
```

### Python (PyTorch)
```python
import pandas as pd
from torch.utils.data import Dataset

class TextDataset(Dataset):
    def __init__(self, csv_file):
        self.df = pd.read_csv(csv_file)
        self.texts = self.df['text'].tolist()
    
    def __len__(self):
        return len(self.texts)
    
    def __getitem__(self, idx):
        return self.texts[idx]

# 使用
train_dataset = TextDataset('proverbs_train_20250823_131449.csv')
```
